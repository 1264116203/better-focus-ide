# ClickHouse 使用规范

## 重要原则

> * 本文件为技术栈规则，执行时严格遵循

---

## 1. JOIN 规范

| 规则 | 说明 |
|------|------|
| 表 JOIN 时大表放在左侧、小表放在右侧 | CK 为列式存储，JOIN 顺序对性能影响显著 |

---

## 2. 查询规范

| 规则 | 说明 |
|------|------|
| 查询 SQL 禁止使用 `select *` | CK 为列式存储，`select *` 性能极差，必须指定字段 |

---

## 3. 去重规范

| 规则 | 说明 |
|------|------|
| 非必要不使用 `distinct` 关键字 | `distinct` 内存占用高 |
| 去重查询优先使用 `group by` 替代 `select distinct` | 优化内存占用 |

---

## 最终回复要求

* 说明 ClickHouse SQL 是否指定了具体字段（非 `select *`）
* 说明 JOIN 是否遵循大表左、小表右的原则
* 说明去重是否使用 `group by` 而非 `distinct`
