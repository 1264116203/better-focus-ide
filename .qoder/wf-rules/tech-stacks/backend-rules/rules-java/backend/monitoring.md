# 监控预警处理响应规范

## 重要原则

> * 本文件为技术栈规则，执行时严格遵循

---

## 1. 响应要求

| 规则 | 说明 |
|------|------|
| 收到报警信息后及时响应 | 排查报警原因，不可忽视 |
| 结合报警信息和频率制定解决方案 | 根据报警模式而非单次事件制定方案 |

---

## 2. 阈值定制

- 根据服务特性定制报警阈值
- 不同服务类型（高并发 API / 批处理任务 / 定时任务）应使用不同阈值策略

---

## 3. 持续高资源占用追踪

| 规则 | 说明 |
|------|------|
| 记录服务/中间件 CPU 持续超过 90% 的时长 | 关注持续时长而非瞬时峰值 |
| 记录服务/中间件 内存 持续超过 90% 的时长 | 关注持续时长而非瞬时峰值 |

---

## 最终回复要求

* 说明是否及时响应报警
* 说明是否制定了针对服务特性的阈值策略
* 说明是否记录了持续高占用时长
