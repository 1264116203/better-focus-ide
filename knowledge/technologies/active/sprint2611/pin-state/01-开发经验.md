# 卡片固定是一份全局状态

日期：2026-11-13

## 旧行为

图钉曾经只写进程内的 `userPinned`。没点过时是 `nil`，新卡片走设置里的 `pinByDefault`（默认开）。进程退出后 `userPinned` 丢掉，下一张卡片又按设置默认值钉住。

日志能对上：2026-11-13 14:36 在通知上把图钉关掉（`pinned=false`），14:42 进程重启后没有这份记忆，设置里仍是 `"pinByDefault": true`。

## 现行行为

提问、权限、通知、待办、历史共用 `Settings.pinByDefault`。卡片图钉和设置里的「卡片固定展示」写的是同一份值，并落盘。换卡片调用 `refreshPinned()`，只读这项设置，不再另记一份进程内覆盖。

`handleSettingsChanged()` 发现这项变了就套用，不能再写回设置，否则和图钉形成回路。

新安装的默认值仍是固定。已经关掉的用户以 settings.json 里的值为准。
